# Example and generated outputs

The [reference](reference/README.md) directory contains verified example
results from the bundled 60-second recording: the complete channel-event and
unit-assignment tables and their manifests. These curated files are tracked;
the two large CSVs use Git LFS (`git lfs pull`).

Running the documented demo creates the complete result tree under
`outputs/demo-60s/`, including the per-channel/per-unit exports. Those locally
generated directories remain ignored by Git. The compact reference is not a
substitute for running and verifying the complete demo.
