# Example and generated outputs

The [reference](reference/README.md) directory contains the verified prediction
CSV, JSON summary, and PNG figure from the bundled 240-second replay.

The documented demo writes new results to `outputs/demo_prediction/`.
That local runtime directory remains ignored by Git, so rerunning the demo
does not overwrite the tracked reference files.
